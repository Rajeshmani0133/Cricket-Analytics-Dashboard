# Cricket Players Analysis | Power BI

## Project Overview
This project uses Microsoft Power BI to analyze cricket player performance through interactive visualizations. It helps users explore player statistics, compare performance, and identify patterns in the available cricket dataset.

## Objectives
- Analyze cricket player performance.
- Compare statistics between players.
- Identify top-performing players based on available metrics.
- Present player statistics through interactive charts and KPIs.
- Make cricket performance data easier to understand.

## Tools & Technologies
- Microsoft Power BI
- Power Query
- DAX
- Data Cleaning and Transformation
- Data Visualization

## Dashboard Features
- Player performance comparisons.
- Statistical summaries using KPI cards.
- Charts for comparing available player metrics.
- Interactive filtering to explore the dataset.
- Visual summaries of player performance.

## Key Skills Demonstrated
- Data preparation using Power Query
- Data modeling
- DAX calculations, where required
- Comparative analysis
- Interactive report development
- Data storytelling

## How to View the Project
1. Download the `Cricket Players Analysis.pbix` file.
2. Open it using Microsoft Power BI Desktop.
3. Explore the available charts, statistics, and filters.

## Files Included
- `Cricket Players Analysis.pbix` — Power BI dashboard file
- `README.md` — Project documentation

## Conclusion
This project demonstrates the use of Power BI to transform cricket statistics into an interactive analytical report for comparing player performance and exploring insights from sports data.
